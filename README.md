A one-line joke about office life, written by a small deterministic Node
program (`main.ts`, standard library only). The program writes a single
sentence to `/output/entry.txt` — the kind of line you send a colleague
after a meeting that should have been an email:

> The meeting that should've been an email ended by scheduling a follow-up meeting to discuss the email it replaced.

Run it with `node main.ts`. It validates the joke (one line, 1–200
characters), writes it to `/output/entry.txt`, and reads it back to confirm
the exact bytes before exiting.
